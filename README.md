An offline guide and progress tracker for all 55 PlayStation 5 trophies in *Grand Theft Auto VI*. Browse the checklist, mark progress, review the platinum roadmap, and open each trophy's guidance and cited sources.

## Run locally

Serve the `app/` directory as the site root with any static HTTP server, then open `index.html`. The guide uses local files and saves checklist progress in the browser. No app build step is needed.
